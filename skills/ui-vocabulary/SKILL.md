# UI vocabulary

When the user describes a pattern, answer with:

1. **The term** (and its common synonyms across design systems).
2. **One line** on what it is and when it's the right tool.
3. **The neighbor it's often confused with**, and the difference.

Look the term up in `GLOSSARY.md`. If the description matches an AI smell, also give the smell id from `SMELLS.md` and the better pattern from `SINKS.md`.

Keep it short. Don't redesign the user's screen.
