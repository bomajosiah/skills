# Eval — ia-vocabulary

Ask these one at a time.

1. "What's the term for a page that lists all projects before I open one?"
   Expected: Collection / index; possibly Collection → detail pattern.

2. "What's it called when the navigation inside a customer changes to Overview, Orders, Notes, Billing?"
   Expected: Local navigation / object subnavigation.

3. "What's the IA term for when the same thing can sensibly live in two categories?"
   Expected: Polyhierarchy.

4. "What's the thing where you show a summary and users click into progressively more detail?"
   Expected: Drill-down.

5. "What's it called when an AI stuffs the entire product onto the dashboard?"
   Expected: Everything Dashboard, clearly labeled a working term.

6. "What's the research method where users try to find things in a text-only menu hierarchy?"
   Expected: Tree testing.

7. "What's the difference between taxonomy and ontology?"
   Expected: taxonomy = categorization/labels; ontology = kinds of things + relationships.
